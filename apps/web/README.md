This app is the web version of Ahsan Enterprise dashboard inside the monorepo. It focuses on day-to-day operational workflows such as file tracking, importer and staff information, balance views, and changelog visibility.

## What this app includes

- Next.js 16 App Router architecture for route-based features
- TypeScript-first codebase with shared types from workspace packages
- Firebase-backed authentication and data access
- Tailwind CSS v4 styling with shared design tokens
- Reusable UI and logic from shared monorepo packages

## Main areas

- Authentication and protected app shell
- User role based access
- File and changelog related pages
- Importer information and balance pages
- Staff information and balance pages

## Tech snapshot

- Framework: [Next.js v16 (App Router)](https://nextjs.org)
- Language: [TypeScript](https://www.typescriptlang.org)
- Auth: [Firebase Authentication](https://firebase.google.com/docs/auth)
- Data: [Firebase Realtime Database](https://firebase.google.com/docs/database)
- Styling: [Tailwind CSS v4](https://tailwindcss.com)
